## Screenshot Guidelines

### Capturing Screenshots
1. Use full HD resolution (1920x1080)
2. Capture in Chrome browser
3. Include relevant UI elements
4. Show interactive states when applicable

### File Naming Convention
- Use descriptive, lowercase names
- Separate words with hyphens
- Include section or feature name
- Use `.png` format for quality

### Browser Settings
- Chrome DevTools disabled
- Full screen mode
- No browser UI visible
- Standard zoom level (100%)
